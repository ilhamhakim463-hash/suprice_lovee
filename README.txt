💌 SURPRISE LOVE WEBSITE
========================

CARA PAKAI:
-----------
1. Buka file "index.html" di browser (Chrome / Firefox / Edge)
2. Klik amplop merah untuk membuka surat
3. Hati-hati kecil akan berterbangan! 💕

CARA EDIT PESAN:
----------------
Buka index.html dengan Notepad atau text editor, lalu cari bagian ini:

  <div class="message">
    Setiap hari bersamamu ...
  </div>

Ganti teks di dalamnya dengan kata-kata kamu sendiri.
Gunakan <br> untuk ganti baris.

CARA GANTI NAMA:
----------------
Cari:   <div class="name">My Love</div>
Ganti:  <div class="name">Nama Dia</div>

CARA GANTI PENGIRIM:
--------------------
Cari:   Secret Admirer
Ganti dengan nama kamu.

CARA BAGIKAN:
-------------
- Kirim file index.html lewat WhatsApp / Telegram / Google Drive
- Penerima tinggal buka file-nya di browser
- Atau upload ke hosting gratis seperti netlify.com / vercel.com
